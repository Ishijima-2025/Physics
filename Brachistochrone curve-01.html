最速降下曲線-01

 

最速降下曲線とは，よく登場する曲線で，

　ある２点間を重力などの影響で落下する場合にかかる時間が最も短い曲線

の事をいいます（Wikiを参考にしました）

色々なサイトに登場しますが，なかなかしっくり来なかったので，じっくりと考えてみました．

 

注意すべき点は，

　高さH，距離L，で落下する場合には，曲線の形状によらず最終速度は同じ

となります．これは位置エネルギーが運動エネルギーに変換されるだけなので．

ちなみに，摩擦力，粘性抵抗，などは無視，です．

 

ほとんどのサイトに載っている計算方法は，

　変分法

を用いていますが，今回は変分法を用いずに，愚直な計算を行っていきます（Copilotには助けてもらいました）

 

・最短経路を検討する

重力下で自由落下する物体の速度と位置

原点に物体を設置します．いつもとは異なり，下向きに正のｙとします．

$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
\alpha &= g \\
v &= gt \\
y &= \frac{1}{2} gt^2 \\
t^2 &= \frac{2y}{g} \rightarrow t = \sqrt{\frac{2y}{g}}\\
v &= g \sqrt{\frac{2y}{g}} = \sqrt{2gy}\\\\
\end{split}
\end{equation}
}
$$
つまり，速度はyが大きくなるにつれて，徐々に大きくなります．当たり前といえば当たり前

 

異なる速度域を最短時間で通過するには

まずは単純に，２つの領域を考え，それぞれ異なる速度で通過する場合を考えます．

図のように，幅ｈを異なる速度で通過する場合を考えます．このとき，

${ \Large \displaystyle v_1 < v_2 }$

とします．まっすぐ通過するよりもできるだけ速い速度域を多く通過するほうが短い時間で通過できるので，

のような経路が最速となります．

　２L　：　開始と終了との距離
　xi　：　vi領域の通過距離

とすると，

$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
x &= vt \rightarrow t = \frac{x}{v} \\
sin \ \phi_1 &= \frac{L-x}{x_1} \\
x_1 &= \frac{L-x}{sin \ \phi_1} = (L-x) \frac{\sqrt{(L-x)^2 + h^2}}{L-x} \\
&= \sqrt{(L-x)^2 + h^2} \\
sin \ \phi_2 &= \frac{L+x}{x_2} \\
x_2 &= \frac{L+x}{sin \ \phi_2} = (L+x) \frac{\sqrt{(L+x)^2 + h^2}}{L+x} \\
&= \sqrt{(L+x)^2 + h^2} \\
t&= \frac{\sqrt{(L-x)^2 + h^2}}{v_1} + \frac{\sqrt{(L+x)^2 + h^2}}{v_2}
\end{split}
\end{equation}
}
$$

となるｔを最小とすればいいことになります．

$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
((L-x)^2 + h^2)^{1/2} \\
\end{split}
\end{equation}
}
$$

を考えます．

$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
L - x &\equiv z \rightarrow \frac{dx}{dz} = -1 \\
\frac{d}{dx}((L-x)^2 + h^2)^{1/2} &= \frac{d}{dz}\frac{dz}{dx}(z^2 + h^2)^{1/2}\\
&= -\frac{d}{dz}(z^2 + h^2)^{1/2}\\
&= -2z \cdot (- \frac{1}{2})(z^2 + h^2)^{-1/2}\\
&= \frac{L-x}{\sqrt{(L-x)^2 + h^2}} \\
\end{split}
\end{equation}
}
$$

同様に，

$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
\frac{d}{dx}((L+x)^2 + h^2)^{1/2} &= -\frac{L+x}{\sqrt{(L+x)^2 + h^2}}\\
\end{split}
\end{equation}
}
$$

となるので，
$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
\frac{L-x}{v_1 \sqrt{(L-x)^2 + h^2}} - \frac{L+x}{v_1 \sqrt{(L+x)^2 + h^2}} =0\\
\frac{sin \ \phi_1}{v_1 } = \frac{sin \ \phi_2}{v_2} \\
\end{split}
\end{equation}
}
$$
となります．

なにか見たことのあるような式．．．．． ここで，屈折率を考えると，
$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
n = \frac{C}{v}
\end{split}
\end{equation}
}
$$
となるので（C:光速），上の式は，
$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
n_1 \ sin \ \phi_1 = n_2 \ sin \ \phi_2\\
\end{split}
\end{equation}
}
$$
という，”スネルの法則”，そのものとなります！．

 

・　全体の曲線

ここで，下向きに，ｙを取っているので，


$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
\alpha &= g \\
v &= gt \\
y &= \frac{1}{2} gt^2 \\
t^2 &= \frac{2y}{g} \rightarrow t = \sqrt{\frac{2y}{g}}\\
v &= g \sqrt{\frac{2y}{g}} = \sqrt{2gy}\\\\
\end{split}
\end{equation}
}
$$

となり，
時間とともに，速度が上昇する　＝　ｙ，の値が大きくなります．
また，

$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
\frac{sin \ \phi_1}{v_1 } = \frac{sin \ \phi_2}{v_2} = \frac{sin \ \phi_i}{v_i} = Const.\\
\end{split}
\end{equation}
}
$$
となるので，徐々に角度，$ \theta_i $，は大きくなります．
図では，


$$
{ \Large \displaystyle
\begin{equation}
\begin{split}
v_1 \ < \ v_2 \ < \ v_3 \ < \ v_4 \\
y_1 \ < \ y_2 \ < \ y_3 \ < \ y_4 \\
\phi_1 \ < \ \phi_2 \ < \ \phi_3 \ < \ \phi_4 \\
\end{split}
\end{equation}
}
$$

となりますので，下凸，のカーブとなりますね．
